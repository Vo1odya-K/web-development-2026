# Лабораторна робота №3: AI-assisted semantic HTML та SEO

## Опис проєкту

Оптимізація семантичної структури, метаданих та SEO-параметрів вебсторінки тарифних планів FactSpace із використанням підходу AI-assisted аудиту.

## Результати дослідницьких завдань

1. **Semantic HTML:**
   Адаптовано структуру з використанням `header`, `nav`, `main`, `section`, `article` та `footer`. Картки продуктів обгорнуто в `<article>`, а тематичні блоки сторінки — у `<section>`.
2. **Heading Hierarchy:**
   Вибудувано строго послідовну ієрархію заголовків h1 -> h2 -> h3 без пропусків рівнів, що забезпечує коректну доступність (a11y) та SEO-індексацію.
3. **SEO & Metadata:**
   Налаштовано унікальний `<title>`, релевантний `<meta description>` та тег `<link rel="canonical">` для запобігання дублюванню контенту у пошукових системах.
4. **Links vs Buttons:**
   Елементи розмежовано за призначенням: посилання `<a>` використано для якорної навігації по сторінці (`#pricing`, `#contact`), а `<button>` залишено для дій.

## AI-assisted оптимізація (Аналіз рекомендацій)

- **Прийнято:** Заміна `div` на семантичні `<section>` і `<article>`; виправлення ієрархії заголовків $h1 \rightarrow h2 \rightarrow h3$; використання `<a>` замість `<button>` для навігаційних елементів.
