# Лабораторна робота №2: Основи CSS (Box Model, Cascade, Specificity, Inheritance)

## Опис проєкту

Вебсторінка секції тарифних планів, виконана з використанням підходу AI-assisted верстки та чистої CSS-архітектури.

## Результати дослідницьких завдань

1. **Box Model:**  
   Використано глобальний скид `box-sizing: border-box`. Це гарантує, що `padding` та `border` не збільшують задану ширину й висоту елемента, роблячи розрахунок сітки передбачуваним.
2. **Cascade & Specificity:**  
   Уникнуто використання `!important` та надто глибокої вкладеності селекторів. Використано чітку специфічність на основі класів (наприклад, `.btn`, `.btn-primary`).
3. **Inheritance:**  
   Базові властивості шрифту (`font-family`, `color`, `line-height`) задані в `body` і успадковуються дочірніми елементами за замовчуванням.
4. **CSS Variables:**  
   Усі кольори, відступи та шрифти винесені у `:root`. Це забезпечує легке перевизначення тем та масштабність дизайну.
